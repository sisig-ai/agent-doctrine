# Contributing

Keep changes small and explain the behavior they change. Edit canonical doctrine, host overlays, agent sources, or delegation bindings, then run `bun run generate`. Do not hand-edit generated host files.

Run `bun test` and `bun run check:public`. Explain any skipped integration checks. Use synthetic examples and reserved example domains in tests. Do not submit project memory, reflection ledgers, customer records, private hostnames, credentials, or machine-local instructions. Review the entire staged diff before publishing.

The public repository contains reusable policy and tooling. Keep personal operational state in a private fork. An ignore rule is a guard against mistakes, not a confidentiality guarantee.
