When Shell output will enter LLM context, invoke supported commands via `tokensieve` — never bare `git status`/`git log`/`git diff`, `cargo test`, `pytest`, `bun test`, `eslint`, `prettier`, `django test`, `ruff`, `mypy`, `rg`, or `grep`. Examples: `tokensieve git status`, `tokensieve bun test tests/foo.test.ts`, `tokensieve rg pattern`. Explicit invocation only — no PreToolUse auto-allow hooks; do not use rtk. If `tokensieve` is missing from PATH, use the raw command and say so. Hot unsupported noise belongs in `sisig-ai/tokensieve` (`~/tokensieve`), not ad-hoc wrappers.
